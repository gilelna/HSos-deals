Block Pattern Factory

Five Gutenberg-ready block patterns. Each shows a live rendered preview and a collapsible code panel with the block comment markup for WordPress registration. Register patterns in includes/block-patterns.php using register_block_pattern().

Pattern 3 · hs2026/about-dark · Dark Inset About Section

Block structure: wp:group (bg-light-purple section-shell) → wp:group (bg-espresso radius-section-lg section-inset-wrap) → wp:columns → wp:column × 2. Left col: h2 with gold underline span + body paragraphs + wp:buttons. Right col: wp:image (circular with hero-round__img class). Key classes: section-inset-wrap bg-espresso, gold-underline on the span, hero-round__img on the image.

Pattern 5 · hs2026/newsletter-strip · Newsletter Sign-up Strip

Block structure: wp:group (section-shell bg-green-dark) → wp:heading (h2 color-white) + wp:paragraph (body-lg color-white text-muted) + wp:group (form-row) → wp:html (email input) + wp:button (btn-primary). Note: the form row uses the .form-row flex layout class. On mobile (<768px) .form-row stacks vertically.

WordPress Registration — includes/block-patterns.php

<?php /** * HS2026 Block Pattern Registration * File: includes/block-patterns.php */ function hs2026_register_block_patterns() { register_block_pattern_category( 'hs2026', [ 'label' => __( 'HS2026', 'hs2026' ) ] ); // Pattern 1: Hero Golden register_block_pattern( 'hs2026/hero-golden', [ 'title' => __( 'Hero — Text Left / Image Right', 'hs2026' ), 'categories' => [ 'hs2026' ], 'content' => file_get_contents( get_template_directory() . '/patterns/hero-golden.html' ), ] ); // Pattern 2: Cards 3-col register_block_pattern( 'hs2026/cards-3col', [ ... ] ); // Pattern 3: About Dark register_block_pattern( 'hs2026/about-dark', [ ... ] ); // Pattern 4: Testimonials 2-col register_block_pattern( 'hs2026/testimonials-2col', [ ... ] ); // Pattern 5: Newsletter Strip register_block_pattern( 'hs2026/newsletter-strip', [ ... ] ); } add_action( 'init', 'hs2026_register_block_patterns' );

Tip: Store each pattern's HTML content in patterns/{pattern-slug}.html (auto-registered in WP 6.0+) or load via file_get_contents() as shown above. The patterns/ folder approach is preferred as WordPress 6.0+ auto-discovers and registers them from the theme's patterns/ directory.
