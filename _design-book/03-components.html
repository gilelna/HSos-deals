§1 · Buttons — All Variants

Base: .btn + size modifier (.btn-md or .btn-lg) + variant. Font: Effra Bold · uppercase · +0.08em tracking · pill radius. MD: padding space-3 / space-5  |  LG: padding space-4 / space-6. Minimum touch target: 44px height.

§7 · WP Block Buttons — is-style-* Variants

These styles target .wp-block-button wrappers as used in the Gutenberg block editor. Add the is-style class to the block's additional CSS class field.

is-style-outline-gold

Outline Gold

Gold border + text. Hover fills gold.

is-style-ghost (on dark bg)

Ghost Button

White text, rgba white border. For dark/image sections.

Filter Chip
Active Chip
