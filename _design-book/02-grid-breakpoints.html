§1 · Container Anatomy — 1100px = φ × 680px

The 1100px container. This number was not chosen arbitrarily. 1100 / φ = 680px — the ideal prose reading width (confirmed by readability research: 60–70 characters per line at 18px = ~650–700px). When you center 680px text in 1100px, the remaining 420px creates two margins of 210px each. 420 / 680 = 0.618 = 1/φ. Every empty space is mathematically proportional to the filled space.

§5 · Breakpoints Reference Table

Breakpoints are values, not variables. CSS custom properties cannot be used inside @media rules. Use the values below directly. Convention: max-width for collapse/hide triggers, min-width for progressive enhancement.

Name Value Direction Use case Example rule
xs 479px max-width Mobile portrait only — stack CTAs, hide decorative elements @media (max-width: 479px)
sm 767px max-width Mobile landscape max — stack hero columns, collapse nav links @media (max-width: 767px)
sm+ 768px max-width Grid collapses for golden-grid, col-3, col-2 — used by style-guide @media (max-width: 768px)
md 1023px max-width Tablet max — adjust container padding, intermediate layouts @media (max-width: 1023px)
lg 1280px min-width Wide desktop — enhanced layouts, optional sidebar patterns @media (min-width: 1280px)

§6 · Responsive Behavior — Stacking Rules

≥ 1100px — Full desktop

Full layout

  • Container at 1100px max
  • Golden grid: 61.8 / 38.2
  • card-grid--4 shows 4 columns
  • All hero variants 2-column

769–1099px — Tablet landscape

Fluid container

  • Container padding shrinks via clamp
  • auto-fit grids start collapsing
  • Hero columns still side-by-side
  • card-grid--4 may show 2–3 cols

480–767px — Tablet / Mobile landscape

Stack trigger

  • Hero columns stack vertically
  • golden-grid, col-3, col-2 → 1 col
  • card-grid--4 and --2 → 1 col
  • .hide-sm, .show-sm active

≤ 479px — Mobile portrait

CTA + button stack

  • .hero-btns stacks vertically
  • All buttons go full-width
  • .hide-xs, .show-xs active
  • Reduced container padding
