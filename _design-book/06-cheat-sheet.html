Section alternation law. Never place two dark sections or two light sections adjacent. Rhythm: light → dark → light → dark. Recommended sequence: bg-pink → bg-espresso → bg-warm-cream → bg-green-dark → bg-light-blue → bg-deep-teal → bg-peach → bg-espresso.

§3 · Spacing Scale

All spacing is pt / pb / pl / pr / px / py for padding, mt / mb / ml / mr / mx / my for margin. Suffix = scale step (1–9).

Step Value Padding classes Margin classes Use
sp-1 4px pt/pb/pl/pr/px/py-sp-1 mt/mb/ml/mr/mx/my-sp-1 Icon gap, border inset
sp-2 6px … -sp-2 … -sp-2 Tight inline, badge padding
sp-3 10px … -sp-3 … -sp-3 Close siblings, chip padding
sp-4 ← 16px = 1rem … -sp-4 … -sp-4 Component gaps (= type base)
sp-5 26px … -sp-5 … -sp-5 Card inner rhythm, input padding
sp-6 42px … -sp-6 … -sp-6 Card padding, major element gaps
sp-7 68px … -sp-7 … -sp-7 Narrow section padding
sp-8 ← 110px … -sp-8 … -sp-8 Standard section vertical rhythm
sp-9 178px … -sp-9 … -sp-9 Hero max breathing room

Also available: .mt-auto · .mx-auto · .gap-3/4/5/6
